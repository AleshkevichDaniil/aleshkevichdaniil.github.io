Задача

Спроектировать утилиту с одним главным действием, подключением, так, чтобы статус был понятен с первого взгляда, а платная подписка не мешала основному сценарию. Проект учебный, не для реального клиента.

Процесс

В Open Design я задал платформу (iPhone 390×844), тёмную тему с фиолетовым акцентом и три состояния главной кнопки: выключено, подключение, включено. Результат уточнял запросами: различимость состояний, поиск по списку локаций, видимость кнопки на paywall без прокрутки. Готовые экраны проверил на обрезку и переносы цен.

Результат

Пять-шесть экранов: главный (три состояния), список локаций с поиском, paywall, настройки, экран «что включено». Прототип показывает подключение и выбор локации.
